## Critical Findings Summary

1. **No privacy policy or consent mechanism** — The app collects precise location, contacts, and identity data without any visible privacy notice or consent dialog.
2. **Plaintext HTTP for sensitive data** — The PHP backend endpoints use HTTP, transmitting passwords and location data unencrypted.
3. **Passwords stored in plaintext** — The PHP backend returns actual passwords (not reset tokens), proving plaintext storage.
4. **Excessive data access during OTP validation** — The friend validation flow downloads the entire user database to find a phone number match.
5. **No data subject rights** — No mechanisms for data access, correction, portability, or deletion requests.
6. **Continuous location tracking without consent** — GPS tracking starts automatically on sign-in with no opt-out.
