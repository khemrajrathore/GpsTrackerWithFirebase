# PA-001: User Registration & Account Creation

## Overview
| Field | Value |
|-------|-------|
| **PA ID** | PA-001 |
| **Name** | User Registration & Account Creation |
| **Description** | Collection and processing of personal data during user account registration. Users provide their name, email address, phone number, and password to create an account. The app creates a Firebase Authentication record and stores the full user profile in Firebase Realtime Database. |
| **Processing Type** | Collection, Storage, Transmission |
| **Lawful Basis** | Consent (user-initiated registration) |
| **Data Controller** | App Operator (BuckleUp / GpsTracker) |

## Data Subjects
| Subject | Description |
|---------|-------------|
| App Users | Individuals who register for an account in the GPS Tracker application |

## Data Elements Collected
| # | Data Element | Category | Sensitivity | Source | Evidence |
|---|-------------|----------|-------------|--------|----------|
| 1 | Full Name | Identity | MEDIUM | User input (EditText `regname`) | `Register.java:82` |
| 2 | Email Address | Contact / Authentication | HIGH | User input (EditText `regemail`) | `Register.java:83` |
| 3 | Phone Number | Contact / Identity | HIGH | User input (EditText `regphnumber`) | `Register.java:80` |
| 4 | Password | Authentication | CRITICAL | User input (EditText `regpassword`) | `Register.java:81` |
| 5 | OTP Code | Authentication | HIGH | App-generated (initialised to "0") | `Register.java:110` |
| 6 | OTP Validity | Authentication | MEDIUM | System-generated (`System.currentTimeMillis()`) | `Register.java:111` |
| 7 | Firebase UID | Identity | HIGH | Auto-generated by Firebase Auth | `Register.java:103` |

## Data Flows
```
User Input (Registration Form)
    │
    ├──► Firebase Authentication (HTTPS)
    │      • email, password → createUserWithEmailAndPassword()
    │      • Creates auth record, returns UID
    │
    └──► Firebase Realtime Database (HTTPS)
           • Path: /Register/{uid}/
           • Fields: email, name, phonenumber, otp="0", otpvalidity
```

## Data Storage & Retention
| Storage Location | Data Stored | Protocol | Retention |
|-----------------|-------------|----------|-----------|
| Firebase Authentication (Google Cloud) | Email, hashed password, UID | HTTPS | Until account deletion |
| Firebase Realtime Database (`/Register/{uid}/`) | Name, email, phone, OTP, OTP validity | HTTPS | Indefinite (no deletion policy) |

## Third Parties / Processors
| Third Party | Role | Data Shared | Legal Basis |
|------------|------|-------------|-------------|
| Google Firebase Authentication | Processor | Email, password | Contract (Firebase ToS) |
| Google Firebase Realtime Database | Processor | Name, email, phone number, OTP, OTP validity | Contract (Firebase ToS) |

## Security Measures
| Measure | Status | Notes |
|---------|--------|-------|
| Transport encryption (Firebase) | ✅ Implemented | HTTPS to Firebase |
| Password hashing (Firebase Auth) | ✅ Implemented | Firebase Auth handles hashing |
| Input validation (email) | ✅ Implemented | `Patterns.EMAIL_ADDRESS` matcher |
| Input validation (phone) | ⚠️ Partial | Only checks length == 10 |
| Rate limiting | ❌ Missing | No registration rate limiting |

## Privacy Risks & Issues
| # | Risk | Severity | Description |
|---|------|----------|-------------|
| 1 | No privacy notice / consent dialog | HIGH | Registration proceeds without showing a privacy policy or obtaining explicit consent |
| 2 | No data deletion mechanism | MEDIUM | No way for users to delete their registration data |
| 3 | No age verification | MEDIUM | No age-gate to prevent minors from registering |
